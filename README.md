# No more accounts

Plugin για το WordPress που αποτρέπει τη δημιουργία νέων λογαριασμών χρηστών — ακόμα και σε επίπεδο βάσης δεδομένων, μέσω SQL triggers, ώστε η προστασία να ισχύει και για κώδικα που παρακάμπτει το WordPress.

## Λειτουργίες

Οι ρυθμίσεις βρίσκονται στο μενού **Χρήστες → No more accounts** και προσφέρουν τρεις προστασίες:

1. **Αποτροπή δημιουργίας χρηστών μέσω REST API** — Το endpoint δημιουργίας χρήστη του WordPress REST API απενεργοποιείται και, για μη συνδεδεμένους επισκέπτες, ολόκληρο το endpoint χρηστών εμφανίζεται ανύπαρκτο (αποτρέπεται έτσι και το user enumeration). Το wp-admin συνεχίζει να λειτουργεί κανονικά.

2. **Αποτροπή δημιουργίας νέων χρηστών (οποιουδήποτε ρόλου)** — Κανένας νέος χρήστης δεν μπορεί να δημιουργηθεί: ούτε από το wp-admin, ούτε από φόρμες εγγραφής, ούτε από plugins, ούτε καν με απευθείας εντολές στη βάση δεδομένων (SQL trigger στον πίνακα χρηστών).

3. **Αποτροπή δημιουργίας νέων administrators** — Επιτρέπονται νέοι χρήστες, αλλά κανείς δεν μπορεί να γίνει administrator: ούτε νέος λογαριασμός με ρόλο διαχειριστή, ούτε αναβάθμιση υπάρχοντος χρήστη σε διαχειριστή (privilege escalation), ούτε καν με απευθείας εντολές στη βάση δεδομένων (SQL triggers στον πίνακα usermeta).

Οι προστασίες 2 και 3 είναι αμοιβαία αποκλειόμενες (η 2 καλύπτει και την 3) και απαιτούν την εγκατάσταση των SQL triggers, η οποία γίνεται με ένα κουμπί από τη σελίδα ρυθμίσεων. Η σελίδα ελέγχει και εμφανίζει αν ο χρήστης της βάσης έχει τα απαραίτητα δικαιώματα (`TRIGGER`) και αν τα triggers είναι σωστά εγκατεστημένα.

Όλα τα μπλοκαρίσματα γίνονται διακριτικά, με γενικά μηνύματα σφάλματος που δεν αποκαλύπτουν την ύπαρξη του plugin.

## Εγκατάσταση

1. Ανεβάστε τον φάκελο `no-more-accounts` στον κατάλογο `wp-content/plugins/`.
2. Ενεργοποιήστε το plugin από τη σελίδα των Προσθέτων του WordPress.
3. Μεταβείτε στο **Χρήστες → No more accounts**, εγκαταστήστε τα triggers και ενεργοποιήστε τις προστασίες που θέλετε.

Κατά την απενεργοποίηση του plugin τα triggers αφαιρούνται από τη βάση· κατά την απεγκατάσταση αφαιρούνται και οι ρυθμίσεις.
