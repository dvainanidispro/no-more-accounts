# No more accounts

Αποτρέπει τη δημιουργία νέων χρηστών στο WordPress σε επίπεδο βάσης δεδομένων, μέσω SQL triggers στον πίνακα των χρηστών.

## Περιγραφή

Το plugin δημιουργεί SQL trigger στον πίνακα χρηστών (με υποστήριξη οποιουδήποτε table prefix) που αποτρέπει την εισαγωγή νέων εγγραφών όταν η αντίστοιχη επιλογή είναι ενεργή. Η αποτροπή γίνεται στη βάση δεδομένων και όχι σε επίπεδο WordPress, ώστε να καλύπτει κάθε πιθανό τρόπο δημιουργίας χρήστη.

## Ρυθμίσεις

Οι ρυθμίσεις του plugin βρίσκονται στο μενού **Χρήστες → No more accounts**.

- **Αποτροπή δημιουργίας νέων χρηστών μέσω REST API** (`nma_prevent_api_users`) — για μη συνδεδεμένους όλο το endpoint `/wp/v2/users` εμφανίζεται ανύπαρκτο (μπλοκάρει και το user enumeration)· για συνδεδεμένους αφαιρείται μόνο το `POST` (προστασία σε επίπεδο WordPress, χωρίς trigger)
- **Αποτροπή δημιουργίας νέων χρηστών** (`nma_prevent_users`)
- **Αποτροπή δημιουργίας νέων administrators** (`nma_prevent_admins`)

## Εγκατάσταση

1. Ανεβάστε τον φάκελο `no-more-accounts` στον κατάλογο `wp-content/plugins/`.
2. Ενεργοποιήστε το plugin από τη σελίδα των Προσθέτων του WordPress.

## Changelog

### 0.4.2

- Οι δύο επιλογές αποτροπής σε επίπεδο βάσης (χρήστες / administrators) εμφανίζονται πλέον ως radio με τρεις τιμές (τα options στη βάση παραμένουν ίδια).
- Διευκρίνιση στη σελίδα ρυθμίσεων για το πότε το REST endpoint χρηστών είναι ορατό σε συνδεδεμένους.

### 0.4.1

- Το option του REST API αποκρύπτει πλέον για μη συνδεδεμένους ολόκληρο το endpoint χρηστών (`/wp/v2/users*`, GET και POST) — αποτρέπεται και το user enumeration. Για συνδεδεμένους εξακολουθεί να αφαιρείται μόνο το POST.

### 0.4.0

- Νέο option «Αποτροπή νέων χρηστών μέσω REST API» (`nma_prevent_api_users`): αφαιρεί το POST handler του `/wp/v2/users`, ώστε το endpoint να εμφανίζεται ανύπαρκτο (αυθεντικό `rest_no_route` 404).

### 0.3.3

- Διόρθωση: δεν επιχειρείται πλέον αποστολή emails ειδοποίησης νέου χρήστη όταν η δημιουργία έχει μπλοκαριστεί (εξαλείφθηκαν PHP warnings στη σελίδα «Προσθήκη χρήστη»).

### 0.3.2

- Ενιαίος handler αποτροπής σε επίπεδο WordPress (filter `wp_pre_insert_user_data`): όλοι οι δρόμοι δημιουργίας χρήστη (admin, REST, εγγραφή κ.λπ.) επιστρέφουν το κοινό γενικό σφάλμα του core.
- Καταργήθηκε ο ειδικός χειρισμός του REST API.

### 0.3.1

- Το μήνυμα σφάλματος του trigger έγινε γενικό («Unknown error») ώστε να μην αποκαλύπτει το plugin.
- Το REST API επιστρέφει το γενικό σφάλμα του core σε μπλοκαρισμένη δημιουργία χρήστη (αντί για PHP fatal).
- Ειδοποίηση «Η δημιουργία χρηστών είναι μπλοκαρισμένη.» στη σελίδα «Προσθήκη χρήστη» όταν η προστασία είναι ενεργή.

### 0.3.0

- Υλοποίηση αποτροπής δημιουργίας χρηστών μέσω SQL trigger (BEFORE INSERT στον πίνακα χρηστών).
- Εγκατάσταση/επιδιόρθωση/αφαίρεση του trigger από τη σελίδα ρυθμίσεων, με έλεγχο κατάστασης.
- Αφαίρεση του trigger κατά την απενεργοποίηση και την απεγκατάσταση του plugin.

### 0.2.0

- Σελίδα ρυθμίσεων (Χρήστες → No more accounts) με τις 2 επιλογές και έλεγχο δικαιωμάτων TRIGGER.
- Link «Ρυθμίσεις» στη σελίδα των plugins.

### 0.1.0

- Αρχική δομή plugin (χωρίς λειτουργικότητα ακόμα).
